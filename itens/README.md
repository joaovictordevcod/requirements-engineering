# Rascunhos dos itens de informação

Cada item de informação é escrito aqui primeiro, em Markdown, e passa pela
revisão no PR. Depois de aprovado, o texto é copiado para o Google Docs.
Assim o histórico de autoria e de revisão fica registrado.

```
itens/
├── 1-elicitacao/      EL-01 a EL-06
├── 2-analise/         AN-01 a AN-06
├── 3-especificacao/   ES-01 a ES-08
└── 4-validacao/       VA-01 a VA-05
```

- **Nome do arquivo:** `<ID>-<assunto>.md`, por exemplo
  `EL-02-plano-de-elicitacao.md`.
- **Início do arquivo:** todo arquivo começa pelo bloco de identificação do
  [modelo de item](../docs/documento/modelo-item-de-informacao.md).
- **Diagramas:** ficam em `modelos/` e são citados no texto pelo nome da figura.
